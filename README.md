# Forest Fire Model — Work in Progress

This repository contains a **personal research and passion project** exploring stochastic forest-fire models,
self-organized criticality, oscillatory dynamics, and scaling laws.

The codebase is **under active development**. Structure, APIs, and implementations may change as the project evolves.

## Status
- Research-oriented, exploratory
- Optimised large-scale simulations
- Advanced statistical analysis tools
- Not yet packaged or version-stable

This repository is shared for transparency, learning, and portfolio purposes.
